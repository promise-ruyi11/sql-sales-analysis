# SQL Sales Analysis Project

## Overview
This project analyzes Global Retails sales data using SQL queries.

## Objectives
- Calculate total sales
- Identify top 5 customers
- Analyze sales by region
- Track Yearly & monthly sales trends
- Analyze sales and profit by sub-category

## 📂 Dataset

This project uses the **Global sales** dataset, which contains retail sales transactions used to analyze sales performance, profit, customer behavior, and regional trends.

### Columns

| Column Name | Description |
|--------------|-------------|
| Row ID | Unique identifier for each record |
| Order ID | Unique order number |
| Order Date | Date the order was placed |
| Ship Date | Date the order was shipped |
| Ship Mode | Shipping method used |
| Customer ID | Unique customer identifier |
| Customer Name | Customer's name |
| Segment | Customer segment |
| Country | Customer's country |
| City | Customer's city |
| State | Customer's state |
| Postal Code | Postal code |
| Region | Sales region |
| Product ID | Product identifier |
| Category | Product category |
| Sub-Category | Product subcategory |
| Product Name | Name of the product |
| Sales | Sales amount |
| Quantity | Quantity sold |
| Discount | Discount applied |
| Profit | Profit generated |

## Key Insights
- Certain regions generate higher revenue
- Top customers contribute a large percentage of total sales
- Sales trends vary across months
- Some sub-categories generate high sales but low profit, indicating potential cost or pricing issues
- High-profit sub-categories contribute significantly to overall business performance
